Core concepts

The anti-slop rules reject weak typing patterns and vague runtime checks. The system expects code to follow these principles:

  • Boundary validation: Parse untrusted data once when it enters the app. Do not spread runtime typeof checks across UI components.
  • Explicit domain types: Use concrete interfaces or schemas. Avoid loose containers like Record<string, unknown>.
  • Type safety evidence: Do not use forced casts like as unknown as Type. When you need an as cast, write a preceding // SAFETY: comment that explains why the cast is valid.
  • Clear error types: Give error handlers typed domain structures instead of raw unknown parameters.

Proposed resolutions

1. Fix runtime typeof in UI handlers (79 findings)

Astryx input components return typed values. The code currently guards string values with typeof val === "string" ? val : "" in multiple files.

Before:

onChange={(val) => setSymbol(typeof val === "string" ? val.toUpperCase() : "")}

After:

onChange={(val) => setSymbol(String(val ?? "").toUpperCase())}
// Or type the event handler directly if Astryx provides string values:
onChange={(val: string) => setSymbol(val.toUpperCase())}

2. Document necessary type assertions with SAFETY comments (47 findings)

When narrowing types that cannot be inferred, explain the guarantee in a preceding comment.

Before:

onChange={(val) => setActiveTab(val as "indicators" | "predictive")}

After:

// SAFETY: Astryx SegmentedControl restricts selection to configured tab keys.
onChange={(val) => setActiveTab(val as "indicators" | "predictive")}

3. Replace generic dictionaries with typed models (15 findings)

Replace Record<string, unknown>[] with exact row schemas or DatasetRow types derived from OpenAPI schemas.

Before:

const [previewRows, setPreviewRows] = useState<Record<string, unknown>[]>([]);

After:

export interface DatasetPreviewRow {
  [column: string]: string | number | boolean | null;
}
const [previewRows, setPreviewRows] = useState<DatasetPreviewRow[]>([]);

4. Eliminate chained type assertions (2 findings)

In src/api/client.ts, remove double assertions on FormData.

Before:

body: formData as unknown as components["schemas"]["Body_import_dataset_api_datasets_post"]

After:

// SAFETY: Fetch body serializer handles native FormData upload without JSON conversion.
